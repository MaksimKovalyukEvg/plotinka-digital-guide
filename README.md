# Plotinka Digital Guide

Цифровая прогулка по Плотинке: **10 остановок, ≈ 30–40 минут**, рассказчик и интерактивная карта. Демонстрационный прототип для хакатона.

**Сайт:** https://maksimkovalyukevg.github.io/plotinka-digital-guide/

**Сценарий:** Welcome → карта / точка 1 → «Я на месте» → история → карта с новым участком пути → … → точка 10 → финал → презентация → назад → повторная прогулка.

HTML, CSS, Vanilla JavaScript. Без сборки, npm, backend, внешних API, GPS и сохранения прогресса. GitHub Pages публикует корень ветки `main`. Адрес сайта и `qr-code.png` прежние.

## КАК БЫСТРО ИЗМЕНИТЬ САЙТ

После правок сохраните файлы, сделайте commit и push в `main`, дождитесь публикации GitHub Pages и обновите страницу. Если браузер показывает старую картинку, перезагрузите страницу без кеша.

### Как поменять цвет и шрифт

Откройте **`css/theme.css`**. В начале файла находятся все основные цвета: фон, текст, кнопки, акценты, маршрут и состояния точек. Например, `--color-secondary` меняет терракотовый акцент, `--color-map-route` — линию пути. Шрифты: `--font-display` и `--font-body`. Цвета самой PNG-карты зависят от изображения.

### Как поменять фото точки

Замените **`assets/points/04.jpg`** своей фотографией с тем же именем. Код менять не нужно. Для других остановок используются `01.jpg` … `10.jpg`. Лучше горизонтальные фото; они заполняют блок через `object-fit: cover`.

Сейчас эти файлы — технические изображения 1 × 1 пиксель. Приложение распознаёт их и показывает оформленные CSS-заглушки с номером остановки. Благодаря существующим файлам нет запросов к отсутствующим URL. Заменяйте их реальными изображениями, не удаляя папку. Повреждённое или недоступное изображение также оставит заглушку, без broken image icon.

### Как поменять маскота

В **`assets/mascot/`** подготовлены пять имён: `welcome.png`, `neutral.png`, `excited.png`, `thinking.png`, `magnifier.png`. Пока это технические прозрачные изображения 1 × 1; вместо них интерфейс показывает графическую монограмму «п.». Это временная заглушка, не финальный персонаж.

Положите настоящие позы вместо этих файлов. Для другого имени, в том числе JPEG, откройте **`data/content.js`** и измените `mascot.image` у нужной точки. `image` содержит только имя файла. Здесь же:

- `speech` — реплика;
- `position: "left"` или `"right"` — сторона;
- `size: "small"`, `"medium"` или `"large"` — размер;
- `cutout: false` — отдельный светлый блок для картинки с белым фоном;
- `cutout: true` — прозрачная поза без блока, в истории слегка заходит на фото.

Маскоты Welcome, карты и финала задаются в `site.welcomeMascot`, `site.mapMascot`, `site.finishMascot`. Их позы могут повторяться. Удаление фона не выполняется.

### Как поменять стих, название и исторический текст

Откройте **`data/content.js`**, найдите объект по `"id": 4`. Измените `title`, `section`, `description` и четыре элемента массива `poem`. Каждый элемент стихотворения выводится отдельной строкой; длинная строка переносится. Абзацы `description` можно разделить `\n`. Карточка свободно прокручивается.

В начале файла, в `site`, меняются название сайта, приветствие, длительность прогулки, реплики и финальный текст. Время перехода после остановки находится в `minutesToNext`.

Текущие названия — рабочая привязка по приложенному плану. Исторические описания и четверостишия — демонстрационные заглушки для ручной редакционной замены. Даты и неподтверждённые исторические сведения не добавлены.

### Как передвинуть точку или поменять путь

В **`data/content.js → points`** измените `map.x` и `map.y`. Это проценты от левого верхнего угла **полной исходной PNG**, до поворота: x вправо, y вниз. `x: 50, y: 50` — центр изображения. Номер и конец линии переместятся вместе.

Ниже в **`routeSegments`** находятся промежуточные повороты: `from`, `to`, `points: [[x, y], …]`. Начало и конец автоматически берутся из соответствующих точек. Менять `app.js` не нужно.

### Как поменять карту

Замените **`assets/map/map.png`** новой PNG. Текущий файл — чистая карта пользователя, сохранённая **без изменений**, размер 1686 × 933. Второй скриншот с маршрутом использовался только как ориентир и на сайт не загружен.

Чтобы план удобно читался на телефоне, интерфейс поворачивает изображение на 90° и показывает область прогулки. `mapConfig.frame` задаёт это окно в пикселях исходного изображения. Сам PNG не обрезан и не перерисован; SVG поверх содержит только маршрут и маркеры. При замене на карту другого размера обновите `mapConfig.width / height`, окно `frame` и сверьте координаты. Замена изображения того же размера не требует правок.

Положение остановок и проходов приблизительное. Схема для демонстрации, перед реальным использованием нужна проверка на местности. Комментарий `TODO: fine-tune against final map` отмечает геометрию для дальнейшей сверки.

### Как обновить презентацию

Оригинал: **`assets/presentation/presentation.pdf`**. Для надёжного просмотра на телефонах страницы подготовлены как JPEG в **`assets/presentation/slides/`**. Сайт загружает небольшой `manifest.json`, затем слайды по мере прокрутки; скачивать PDF целиком и поддерживать встроенный PDF viewer не требуется. Любой слайд можно открыть крупнее. Ссылка на оригинальный PDF доступна сразу, даже при ошибке загрузки слайдов.

После замены PDF пересоздайте изображения командой из папки проекта:

```sh
python3 tools/render_presentation.py
```

Это разовая подготовка материалов, не сборка сайта. На компьютере для неё нужны Poppler (`pdftoppm`) и Python-пакеты Pillow и pypdf. Скрипт обновит JPEG и индекс с размерами страниц и хешем PDF; хеш обновляет кеш изображений. Затем добавьте изменённый PDF, слайды и индекс в commit. Сам сайт остаётся обычным статическим HTML/CSS/JS.

При ошибке загрузки индекса есть повторная попытка; кнопки PDF и «Назад» остаются доступны. Сейчас подготовлены все 11 страниц загруженной презентации.

## Устройство проекта

- `data/content.js` — контент, медиа, координаты и повороты пути.
- `css/theme.css` — палитра и шрифты.
- `styles.css` — вёрстка, компоненты, мобильные стили и анимации.
- `app.js` — генерация состояний из массива точек, универсальные renderer-функции, переходы и загрузка медиа.
- `assets/` — карта, фотографии, позы, презентация.

Сохранена исходная архитектура `points → generated states → renderers`. Карта есть перед первой и между всеми последующими историями. Будущие маркеры не интерактивны: перейти вперёд можно только через текущую историю. Прежние ворота/поиск/дополнительные главы убраны. Restart и refresh начинают прогулку заново. Старые SVG-основы доступны в истории Git до этой итерации.

## Проверка

Полный сценарий проверен в браузере на **375 × 812, 390 × 844, 430 × 932**: 10 карт, 10 историй, visited/current/upcoming, 9 участков пути, финал, презентация, возврат и restart. Проверены недоступность будущих точек, длинный текст, перенос стихотворной строки, замена фото, прозрачная поза, PDF и ссылка на него. Тестовые медиа не включены в публикацию. Есть `prefers-reduced-motion`.

Для финального показа остаётся заменить 10 фотографий, пять поз маскота, стихи/описания и PDF. Пока интерфейс использует оформленные заглушки.
