# Plotinka Digital Guide

Interactive digital walking guide по Историческому скверу Екатеринбурга.
**16 historical objects · 6 глав · ≈ 30–40 минут.**

**GitHub Pages:** https://maksimkovalyukevg.github.io/plotinka-digital-guide/

**User flow:** QR → Map → Story → Route → Next point → … → исторический финал → Modern Plotinka → Finish → Restart.

HTML + CSS + Vanilla JavaScript. Без сборки, npm, backend, GPS, сторонних карт и API. GitHub Pages публикует корень `main`. URL и существующий `qr-code.png` сохранены.

## Историческая карта

Основа — предоставленный файл `map svg.svg`. Его неизменённый оригинал сохранён в `assets/plotinka-map-reference.svg`. Для интерфейса из него выделен план `assets/plotinka-map-base.svg` с `viewBox="0 0 1120 1043"`: вода, здания, дорожки и парки. Поверх него расположен отдельный SVG overlay с 16 номерами, состояниями и маршрутами. Старая схема `assets/plotinka-map-legacy.svg` сохранена как резервный исходник.

Позиции всех 16 точек взяты из пронумерованных маркеров предоставленного SVG. Тексты и исторические ID сохранены по заданию: легенда нового SVG содержит расхождения начиная с №7 и не используется как источник названий. В рабочей основе убраны статические номера, внешняя легенда и подписи улиц; динамические номера не дублируются. Маркер №2 немного смещён внутрь карты, выноска указывает его исходную позицию.

Пути следуют нарисованным дорожкам, берегу и мосту; короткие подходы соединяют дорожки с точками зданий. Это демонстрационная схема, не точная навигация. `TODO: fine-tune against final map` оставлен для проверки исторической привязки объектов и доступных проходов на местности.

Для изменения основы редактируйте `assets/plotinka-map-base.svg`. При замене файла обновите `mapConfig.image`, `width / height` и сверьте координаты `points`. Координаты в процентах соответствуют viewBox основы, поэтому карта и SVG overlay масштабируются вместе.

## Где менять содержимое

- **Тексты:** `app.js → points`: `title`, `shortTitle`, `storyTitle`, `description`, `hint`, `mascotText`. Исторические номера `id` — 1–16.
- **Главы:** `chapterNumber` и `chapter` в каждой точке. Общее число глав вычисляется автоматически.
- **Координаты:** `points → x / y`, проценты от левого верхнего угла: 0–100. `labelX / labelY` — позиция подписи «Вы здесь». Изменение координаты автоматически перемещает объект и конец маршрута. `markerOffset: [dx, dy]` в процентах сдвигает только номер; тонкая выноска связывает его с объектом, чтобы соседние номера не сливались.
- **Маршрут:** `points → route`, массив промежуточных поворотов `[[x, y], …]` в тех же процентах. Начало берётся из предыдущей точки, конец — из текущей; в `render()` маршрутов нет.
- **Фото:** `assets/points/01.jpg` … `16.jpg`. Для каждой точки подготовлен `imagePath`. После добавления файла укажите этот путь в `image`, например `image: './assets/points/01.jpg'`. Пустой `image` оставляет CSS-placeholder без запросов к несуществующим файлам. Если заданный файл не загрузился, изображение скрывается и остаётся эскиз.
- **Маскот:** добавьте `assets/mascot.png` и укажите `mediaConfig.mascot: './assets/mascot.png'`. Блок появляется только у точек с `mascotText`. Пока файла нет, реплика работает без изображения.
- **Современная Плотинка:** список `modernIdeas` содержит демонстрационные направления, а не утверждения о реализованных проектах.

## Механики

`points.forEach()` создаёт `pointN`, `routeN` и финальные состояния. Карта возвращается между всеми остановками. Типы точек: `standard`, `gate`, `bridge`, `find`, `final`.

Ворота №2, 6, 7, 15 собираются в коллекцию. №13 сначала предлагает найти фрагмент; «Нашёл» раскрывает текст. После №16 идут последовательность 1723 → 2026 и демонстрационный экран современной Плотинки. Restart сбрасывает посещения, ворота и находки. Перезагрузка страницы начинает прогулку заново.

Карта показывает `visited / current / upcoming`; «Крупнее» увеличивает её внутри отдельной области. Анимации учитывают `prefers-reduced-motion`. Фотографии и маскот необязательны.

Изменения публикуются после commit и push в `main`. QR менять не нужно, пока адрес сайта остаётся прежним.
