# Plotinka Digital Guide

Interactive proof of concept цифровой прогулки по Историческому скверу Екатеринбурга.

**GitHub Pages:** https://maksimkovalyukevg.github.io/plotinka-digital-guide/

**User flow:** QR → Map → Story → Route → Next story → Finish.

Три остановки: Городская плотина, Водонапорная башня, Музей архитектуры и дизайна.
`qr-code.png` ведёт на публичный сайт GitHub Pages.

## Как изменить

- **Тексты:** массив `points` в `app.js`, поля `title`, `shortTitle`, `description`.
- **Изображения:** положите фотографии в `assets/` и укажите в `image` относительный путь, например `./assets/point-1.jpg`. Пока фотографий нет, автоматически показываются CSS-эскизы без битых ссылок.
- **Точки:** добавьте запись в `points` с последовательным `id`, координатами `x/y`, координатами подписи, временем `minutes` и SVG-путём `route` от предыдущей точки. Экраны, переходы и прогресс строятся из массива; схема и общая длительность прогулки редактируются в `mapMarkup` и `render`.

SVG-карта встроена в `app.js`. Она концептуальная: геометрия и время переходов демонстрационные. Это не настоящая навигация. Нет GPS, геолокации, сторонних API, аналитики и backend.

HTML + CSS + Vanilla JavaScript, без сборки и зависимостей. GitHub Pages публикует корень ветки `main`. Изменения публикуются после commit и push. Для локального просмотра достаточно статического сервера.

Состояния: `intro → point1 → route2 → point2 → route3 → point3 → finish`. «Пройти ещё раз» возвращает в `intro`; обновление страницы также начинает прогулку заново. Настройка уменьшения движения учитывается.
